## ✨ 特徴

### 🎯 デュアルホットキーで賢く使い分け

**2 つのホットキーに異なるモードを割り当てて使い分けられます。**

- **ホットキー 1（普通入力）**: スタンダード（Groq）で日常のメモ・チャット（押している間だけ録音）
- **ホットキー 2（ハンズフリー）**: スタンダード（Groq）で重要な議事録（押して開始・もう一度押して停止。長い録音は内部で高精度エンジンへ自動切替）

各ホットキーに以下を個別設定可能：

- ショートカットキー（`<F2>`, `<shift_r>`, `<cmd_r>`, `<ctrl>+<space>` 等）。**「割り当てを外す」ボタン**またはキー捕捉中の **ESC** で「未割り当て」にでき、そのホットキーを無効化できます（片方だけ使いたいとき用。未割り当てのキーは反応しません）
- トリガーモード（`hold`: 押している間録音 / `toggle`: 押して開始/停止）
- 文字起こしモード（**即時入力** / **スタンダード**）
- テキスト整形オン/オフ（既定はモード別：**即時入力=OFF**〔速度優先〕/ **スタンダード=ON**〔録音後にきれいに整形〕。トグルで変更可）と**整え方プリセット**（標準／そのまま／すっきり／箇条書きの 4 種から選択）

### ⚡ その他の主要機能

- **🖥️ Cross-Platform**: Windows / macOS 対応
- **✨ 自動テキスト整形**: 文字起こし結果を読みやすく自動整形（ホットキーごとにオン/オフ可）。発言内容は削らず句読点・表記を整える方針で、**整え方は 4 プリセットから選択**できます — 標準（言いよどみだけ除去）／そのまま（一切削らず句読点だけ）／すっきり（言い直しを整理）／箇条書き（リストに整理）
- **🔢 数字は半角で入力**: 数字を読み上げると漢数字ではなく **半角アラビア数字で入力**されます（全角の数字・英字も半角化）。「十二人→12人」「二〇二六→2026」のような並びや位取り（千二百三十四→1234）に加え、「三時→3時」「百人→100人」のような**助数詞つきの単独漢数字**も半角化します。「一人」「十分（じゅうぶん）」のように数字に読める普通の言葉は**保護リスト**で守れます。設定「数字入力」で **半角化のオン/オフ・助数詞変換のオン/オフ・変換しない語の追加/削除**ができます（既定はすべてオン・保護リストは初期シード入り）
- **🎙️ 高精度・低遅延**: 無音スキップ・音量正規化などの処理は常に最適な設定で自動実行
- **🪟 コンパクトな録音 HUD**: 画面下部中央に小さく出る録音インジケーター（邪魔にならない小型ピル）。状態に応じて**待機（最小）→変換中（小）→録音中（大）の三段階でなめらかに変形**し、Dock／タスクバーの出没に合わせて縦位置も追従します。設定で「ピルを常に表示」にすると待機中も小さなピルを常時表示できます（両 OS・既定オフ・録音開始でそのまま大きく育つ変形付き。**両 OS ともフルスクリーンアプリの利用中は待機ピルを自動で隠します**）。Mac では貼り付け先アプリのアイコンをピル左端に表示します
- **⚙️ GUI 設定**: 設定ウィンドウから簡単に変更。各設定は**開閉できる左サイドバー**から選びます（折りたたむとアイコンだけのレールになり、項目が増えても縦スクロールで全部に届きます）
- **🧊 半透明ガラスデザイン**: 設定・セットアップ画面は画面中央に開く**「浮遊するガラス島」デザイン**。デスクトップが透けるすりガラスの下地の上に、サイドバーやコンテンツが影と光る縁のついた角丸パネルとして浮かびます（Mac は macOS 26 の Liquid Glass、旧 macOS では近似表示。Windows は同系のガラス風配色）。
  Mac では**設定やセットアップ画面を開いている間だけ Dock にアイコンが表示**され、⌘Tab で普通のアプリのように切り替えられます（閉じるとメニューバー常駐だけに戻る。設定「表示」の「Dock に表示」をオンにすると常時表示にできます）。Finder や Launchpad でアプリをもう一度開くとホーム画面が前面に開きます
- **🏠 ホーム画面 / ダッシュボード（両 OS）**: 統計を 3 カードで見せるダッシュボード — **累計入力**（累計文字数＋回数・録音時間＋レベル/進捗バー）、**節約できた時間**（推定節約時間＋「映画 n 本ぶん」等の身近な換算）、**この期間**（「今日⇄今週」を切り替えて期間内の文字数・録音時間・回数を表示）と、最近の履歴（クリックでコピー）。**Mac** は起動時や Dock / Finder から開き直したときに出るメインウィンドウのホーム面で、よく使うアプリの割合やマイクテスト／セットアップガイド再表示カードも置き、サイドバーの「設定」で同じウィンドウのまま設定へ切り替わります。**Windows** は設定ウィンドウの先頭「ホーム」ページで、サイドノッチの「ホームを開く」からも開けます（アプリ別使用状況は Windows の履歴がアプリ情報を持たないため非対応）
- **📜 サイドノッチ（両 OS）**: 画面左端の細いスリット。クリックすると音声入力の履歴パネルが開き、上部の検索フィールドで絞り込み、各行をクリックでコピーできます。録音中はアクセント色で点灯します。設定「表示」の「サイドノッチを表示」で切替（既定オン。検索は Mac＝テキスト・アプリ名／Windows＝テキスト）
- **🕘 入力履歴**: 音声入力をローカルに保存し、ホーム画面やサイドノッチから再コピーできます（Mac＝直近 200 件・貼り付け先アプリ／日時つき、Windows＝直近 10 件・日時つき）。上限を超えると古いものから自動で消えます（統計は履歴と独立した累計のため、履歴が消えても減りません。保存はこの端末のみ・クラウド送信なし）
- **🔊 操作音・メディアダッキング（両 OS）**: 録音の開始／停止を短い操作音で知らせ、録音中だけ再生中メディアの音量を自動で下げます（設定「サウンド」で各オン/オフ・既定オン）
- **📋 最後の入力を再貼り付け（Mac）**: グローバルショートカット（既定 ⌃⌘V）で、直前に入力したテキストをもう一度貼り付けられます（設定「一般」で変更・無効化可）
- **🎯 ダブルタップ Auto-Enter**: 連続入力後に自動で Enter（チャットアプリ向け）
- **🤚 ハンズフリーキー**: 切替キー＋ホットキーで「押して開始・もう一度で停止」のトグル録音に
- **⌨️ JIS（日本語）配列対応**: 記号キーや ¥ / かな / 英数 / 無変換 / 変換 などもホットキーに使える
- **🏆 使用実績（統計＋チャート＋レベル）**: **Mac はホーム画面**、Windows は設定の「実績」タブで、使うほど貯まるレベル・経験値に加え、
  **今日／今週／累計の入力量**をカウントアップ表示し、**期間（週・月・年）を切り替えられる棒グラフ**で日ごと・月ごとの入力量を可視化します。
  タイピングと比べた**推定節約時間**・累計文字数・連続利用日数も確認できる（集計は貼り付け後の処理のみ＝音声入力に待ちを足しません）。
  実績はこの端末のローカルに集計されます（ログイン・アカウント連携はありません）
- **🔄 自動アップデート**: 新バージョンをバックグラウンドで静かに自動確認します（Mac=Sparkle・起動少し後＋数時間おきにサイレント確認 / Win=独自フィード）。
  **Mac は新版を見つけたときだけホーム画面の左上に「⬆ 更新する」ピルが出て**、クリックで更新できます（バックグラウンド確認で勝手にダイアログは出しません）。手動で確認したいときは設定の「バージョン情報」タブのボタンから行います（メニューバーの「アップデートを確認…」項目は廃止）
- **📖 ユーザー辞書（確定置換）**: 設定の「ユーザー辞書」タブで、よく誤変換される語の置き換えルール（変換元 → 変換先）を登録できる。
  文字起こし・整形が終わった文章を貼り付ける直前にローカルで機械置換するため、音声入力に待ちを足しません
- **💬 ライブ字幕（Mac・macOS 26 以降・自分用ビルドのみ）**: 再生中の音声をその場で字幕にして、
  画面下のガラス HUD に出します。メニューバーの「ライブ字幕」または **⌥⌘S** で開始/停止。
  - **2 つのモードがあります**（メニューの「モード」/ 設定タブで切り替え）
    - **翻訳**: 英語を聞いて**日本語に訳して**出す（従来のライブ翻訳）
    - **文字起こし**: 聞いた言葉を**訳さずそのまま**出す。認識する言語は**日本語 / 英語**から選べます
      （Apple の音声認識は言語を指定して動くため、自動判定はしません）
  - **文字起こしはローカルに自動保存されます（議事録）**。`~/Documents/voicekey/transcripts/` に
    `2026-08-28_1432.md` のような Markdown で、確定した文が時刻つきで追記されます
    （**保存するのは文字起こしだけで、訳文は保存しません**）。5 分以上あくと別ファイル＝別の会議になります。
    保存の ON/OFF と「保存先を開く」はメニューと設定タブにあります
  - 設定は **設定ウィンドウの「ライブ字幕」タブ**にまとまっています（モード・認識言語・議事録の保存・
    自動開始・翻訳エンジンとモデル・読み上げ・原文表示・対象アプリ・大きさのリセット・API キーの状態）。
    メニューバーからも同じ操作ができます
  - 既定で**最前面のアプリの音だけ**を対象にするので、裏で流している音楽は字幕に混ざりません
  - 翻訳は既定で **Apple のオンデバイス翻訳**（APIキー不要・無料）。メニューから **Gemini / Groq** にも切り替えられます
    （クラウドは確定した文だけを送り、混雑・失敗時は自動で Apple 翻訳に戻ります）
  - 確定した文は全部訳して読める時間だけ残ります（確定 2 行＋喋っている途中のライブ行の 3 段）。
  - 字幕は**録音ピルと同じ場所（画面下の中央）に固定**で、文が増えると**ピルがそのまま上へ育つ**ように広がります。
    位置は動かせません（右下のグリップで大きさだけ変えられます。メニューの「字幕の大きさをリセット」で既定に戻ります）
  - **音声入力（ディクテーション）をしている間は字幕を隠します**。裏では認識と翻訳を続けているので、
    入力が終われば続きからまた出ます
  - 起動と同時に字幕を始めることもできます（**既定はオフ**。メニュー / 設定タブの「起動時に字幕を自動開始」で切り替え）
  - 訳文の読み上げ（既定オフ）・英語の原文併記（既定オン）もメニューから切り替えられます
  - 初回だけ「システムオーディオを収録するためのアクセス権」の許可が必要です（マイクは使いません）
  - 注: ディクテーション録音中は他アプリの音量が下がる（メディアダッキング）ため、その間は字幕の認識が途切れることがあります
- **🤖 Google Meet 議事録ボット（Mac・macOS 26 以降・自分用ビルドのみ・Chrome が必要）**: 会議の URL を渡すと、
  **ボットが裏で会議に入って文字起こしを議事録として保存**します。メニューバーの「Meet 議事録ボット」→「会議に参加…」。
  - URL 欄はクリップボードの Meet URL を自動で入れます。参加すると `~/Documents/voicekey/transcripts/` に
    追記されます（`- 14:32:05 **山田**: 本日の議題は…`）
  - **文字起こしの方法は 2 つから選べます**（メニューの「文字起こしの方法」・参加していない間だけ変更可）
    - **Meet の字幕を使う**（既定）: Google Meet にもとから付いている字幕を読みます。**話者名が付く**のが利点です
    - **端末内で文字起こし**: 会議の音声を Mac の中だけで文字にします（Apple のオンデバイス認識）。
      音声もテキストも外に出ません。話者名は会議画面から読めたときだけ付きます
  - ボットは**マイクとカメラを切って**入ります。API キーも課金も不要です
  - 端末内モードで記録を始めるときは、ライブ字幕が動いていたら自動で止めます（同じ音を二重に記録しないため）
  - **初回だけ**「ボット用ブラウザで Google にログイン…」から Chrome にログインしてください。
    ログインしておくと自分の会議へ承認なしで入れます（未ログインでもゲストとして参加をリクエストできますが、
    ホストの承認が要ります）
  - ボット用の Chrome は**普段使いの Chrome とは別のプロファイル**（`~/Library/Application Support/voicekey/meetbot-profile`）で
    裏（ヘッドレス）で動くので、作業中のタブには影響しません
  - 退出はメニューの「会議から退出」。voicekey を終了しても Chrome は畳まれます
- **🖥 ローカル文字起こし「ローカル（Apple）」（Mac・macOS 26 以降・自分用ビルドのみ）**: 文字起こしを **Mac の中だけ**で行うモード。
  録音キーの設定で文字起こしエンジンに「Apple オンデバイス音声認識」を選ぶと使えます。
  - **通信も API キーも使いません**。オフラインでも動き、音声が外部に出ません
  - しゃべり終わった瞬間に確定する「即時入力」型です（録音中から並行して認識し、キーを離すと確定）
  - 認識する言語は設定の「言語」に従います。初回だけ言語モデルのダウンロードが走り、進捗が録音 HUD に出ます
  - ライブ字幕と同時に使えます（字幕を出したまま音声入力しても互いに干渉しません）
- **🌏 翻訳して入力（Mac・macOS 26 以降・自分用ビルドのみ）**: 話した内容を**翻訳してから貼り付け**ます
  （本命は「**日本語で話す → 英語が入力される**」）。設定ウィンドウの「**翻訳して入力**」タブで切り替えます。
  - **全体で 1 つのトグル**です（録音キー 1・2 のどちらでも、どの文字起こしエンジンでも同じように効きます）
  - 入力する言語は **英語（既定）/ 中国語（簡体）/ 韓国語 / スペイン語 / 日本語**から選べます
  - 翻訳エンジンは **Apple のオンデバイス翻訳（既定・無料・オフライン）**と **Groq（LLM・API キーが必要）**の 2 択
  - 翻訳するのは**貼り付け直前の最終テキストに 1 回だけ**です。**翻訳に失敗したときは原文がそのまま入力されます**（文章を失いません）
  - 「文章を自動で整える」と同時に使うと整形と翻訳で 2 回 LLM を呼ぶので、速さを優先するなら録音キーの設定で整形をオフにしてください

## 🤖 AI エージェント向けセットアップ手順

> **このセクションは、Claude Code / Cursor / Codex などの AI に「voicekey をセットアップして」と頼んだときに迷わず動けるよう、必要な情報を 1 か所にまとめたものです。**
> **AI へのプロンプト例（コピペ可）**: 「このリポジトリ（`https://github.com/Tomato-1101/voicekey`）を `~/Project` 直下にクローンして、README の『AI エージェント向けセットアップ手順』に従って起動できる状態にしてください。OS は macOS（または Windows）です。Groq の API キーは後で入力するのでスキップしてください。」

### 前提条件チェックリスト（AI がまず確認すべき項目）

| # | 項目 | 確認コマンド | 期待される結果 |
|---|---|---|---|
| 1 | OS | `uname -s` / `ver` | `Darwin`（macOS）または `Windows_NT` |
| 2 | Python 3.10+ | `python3 --version` | `Python 3.10.x` 以上 |
| 3 | git | `git --version` | バージョンが表示される |
| 4 | ffmpeg | `ffmpeg -version` | バージョンが表示される（未インストールなら手順 5 で導入） |
| 5 | ネットワーク | `curl -s https://api.groq.com` | レスポンスが返る（API 文字起こし用） |

### macOS 完全セットアップ（コピペで完結）

```bash
# 1. クローン
cd ~/Project   # 任意のディレクトリ
git clone https://github.com/Tomato-1101/voicekey.git
cd voicekey

# 2. ffmpeg（未インストールなら）
which ffmpeg || brew install ffmpeg

# 3. venv 作成 & 依存関係インストール
python3 -m venv venv
source venv/bin/activate
```

  「入力監視」を許可しても反応しない場合は、案内に従って**アプリを再起動**してください（続きから再開します）。

### 基本的な使い方

1. システムトレイ（Windows）/ メニューバー（macOS）にアイコンが表示される
2. ホットキーを押す（既定: `<f2>` / `<f3>`）
3. 音声入力する
4. ホットキーを離す（`hold` モード）またはもう一度押す（`toggle` モード）
5. 文字起こし結果がアクティブウィンドウに自動入力される

#### ハンズフリー（トグル）録音

設定で「ハンズフリーキー」（例: `<cmd_r>`）を 1 つ決めておくと、
**切替キーを押しながらホットキーを押す**だけで、そのプロバイダーがトグル録音
（1 回で開始・もう一度で停止。キーを押しっぱなしにしなくてよい）になります。
切替キーなしで押せば従来どおりのモード（通常は長押し）です。
※ 先に切替キー（修飾キー）を押してからホットキーを押してください。

**止め方**: 録音を終えるときは**同じホットキーをもう一度押すだけ**です（切替キーは押さなくてよい）。
ハンズフリー録音中は HUD の状態ドットと波形バーが**ティール色**に変わるので（文字ラベルは出しません）、
いまトグル録音中だと色だけで一目で分かります（両 OS）。

## 🎯 デュアルホットキー機能

voicekey は **2 つの独立したホットキー** を設定でき、各ホットキーに異なるモードを割り当てられます。

> **文字起こしモードは 2 種類**: 設定画面では「**即時入力**」（最速・録音中に文字起こしが並行して進み、
> キーを離した瞬間に全文がまとめて入力）と「**スタンダード**」（録音後にきれいな文章にして入力・おすすめ）から選びます。
> モデルの選択は不要で、それぞれ最適なモデルを自動で使います。整形（読みやすく整える処理）は
> 裏で自動的に行われ、ホットキーごとにオン/オフできます。**新規インストール時の既定は
> 録音キー 1 =「即時入力」/ 録音キー 2 =「スタンダード」**。
> **「スタンダード」をハンズフリー録音（トグル）で使うときは、長い録音に強いエンジンへ自動で切り替わります**
> （長時間の議事録でも精度を保つため。切替はアプリが内部で行い、設定は不要です）。

### 使用例

**例 1: 速さと正確さの使い分け**

| スロット | ホットキー | モード | 用途 |
|---|---|---|---|
| ホットキー 1（普通入力） | `<f2>` (hold) | スタンダード | 日常のメモ・チャット（押している間だけ録音・録音後すぐ変換） |
| ホットキー 2（ハンズフリー） | `<f3>` (toggle) | スタンダード | 重要な議事録・正確さ重視（押して開始/停止。長い録音は内部で高精度エンジンへ自動切替） |

**例 2: 言語切替**

| スロット | ホットキー | プロンプト | 用途 |
|---|---|---|---|
| ホットキー 1 | `<ctrl>+<space>` | `Language: Japanese` | 日本語入力 |
| ホットキー 2 | `<alt>+<space>` | `Language: English` | 英語入力 |

### モード比較

| モード | 速度 | 特徴 |
|---|---|---|
| **スタンダード** | **最速** | 既定（おすすめ）。録音後にきれいな文章にして入力（Groq whisper-large-v3-turbo）。日常のメモ・チャット向き。ハンズフリー録音（トグル）のときは長い録音に強いエンジン（ElevenLabs scribe_v1）へ内部で自動切替 |
| **即時入力** | 最速 | 録音中に文字起こしが並行して進む（Deepgram nova-3・ストリーミング）。キーを離した瞬間に全文がまとめて入力されるので待ち時間が最小（実測 0.1 秒） |

> 無音スキップ・整形などの処理は常に最適な設定で自動的に行われます（設定不要）。

## ⚙️ 設定方法

### GUI 設定（推奨）

トレイアイコンをクリックして設定ウィンドウを開く。

#### 📍 General ページ

ホットキー 1 / 2 をそれぞれ：

- **Shortcut**: ホットキー文字列（例: `<f2>`, `<shift_r>`, `<cmd_r>`, `<ctrl>+<space>`）
- **Mode**: `hold` / `toggle`
- **文字起こしモード**: **即時入力** / **スタンダード**（モデルは自動。選択不要。スタンダードのハンズフリー録音時は内部で高精度エンジンへ自動切替）
- **文章を自動で整える**: 結果を読みやすく自動整形するか（オン/オフ）。既定はモード別（即時入力=OFF / スタンダード=ON）で、文字起こしモードを切り替えるとそのモードの既定に追従します（その後トグルで変更可）
- **整え方（プリセット）**: 整形オンのとき、削り方を 4 種から選べます（発言内容を要約・削除しないのは全プリセット共通）— **標準**＝「えーと」などの言いよどみだけ除去（既定）／**そのまま**＝一切削らず句読点・改行だけ整える／**すっきり**＝言い直し・どもりを整理／**箇条書き**＝列挙や手順をリストに整理。自由なプロンプト入力・モデル選択はありません（サーバー側で固定）

共通：

- **Language**: 言語コード（`ja`, `en` 等）
- **ハンズフリーキー**: このキー＋ホットキーでトグル録音にする修飾キー（空で無効）
- **ピルを常に表示**: 待機中も画面下部に小さなピルを常時表示（両 OS・既定オフ・録音開始で大きく育つ）
- **最後の文字起こしを貼り付け（Mac）**: 直前の入力を再貼り付けするグローバルキー（既定 ⌃⌘V・空で無効）

「一般」ページには、上記に加えて次のグループがあります（両 OS）：

- **表示**: ピルを常に表示 / サイドノッチを表示（Mac はさらに「Dock に表示」）
- **サウンド**: 操作音 / 音声入力中はメディアの音量を下げる
- **履歴（Mac）**: 履歴を保存（オフにするとその後の入力を履歴に残しません。履歴は 200 件を超えると古いものから自動で消えます）
- **数字入力**: 数字を半角に変換（マスター）／ 助数詞つきの漢数字も変換（三時→3時）／ **変換しない語**の一覧（追加・削除）。保護リストは「一人」「十分」などの初期シード入りで、数字に読める普通の言葉を守ります

> **JIS（日本語）配列**: Shortcut には記号キー（`-` `=` `[` `;` `/` など）や
> 日本語専用キー（`¥` / `かな` / `英数` / `無変換` / `変換` / `半角全角`）も指定できます。
> ただし環境・IME によっては一部の日本語キーがアプリに届かず使えない場合があります。

## 🎚️ 音声前処理

API に送る前に、録音音声を **音量正規化（Peak+RMS ハイブリッド方式）** で整えます。

| 項目 | 値 |
|---|---|
| 目標 RMS | -20 dBFS（人声に適した一般値） |
| ピーク上限 | -3 dBFS（音割れ防止のヘッドルーム） |
| 処理時間 | numpy のみで <1ms（5 秒音声でも誤差レベル） |

### 効果

- **小声で録音した音声**：API 文字起こしに十分なゲインまで持ち上げる
- **大声・近距離マイク**：ピーク上限で抑え込み、クリッピングによる文字化けを防ぐ
- **完全無音**：そのまま透過（ゲイン発散の防止）

ノイズ対策（ファン音・背景雑音等）は API モデル（Whisper）側が十分に行うため、ローカルでのノイズリダクションは実装していません。

設定ウィンドウの **Advanced → Audio Preprocess** で ON/OFF を切替可能（既定 ON）。

## 🔧 トラブルシューティング

### テキストが入力されない

**Windows**:

- 入力先アプリが管理者権限なら、voicekey も管理者権限で実行する。
- 他のアプリのホットキーと競合していないか確認。

**macOS**:

- システム設定 → プライバシーとセキュリティ → **アクセシビリティ** に voicekey（または Python）を追加。
- 同じく **入力監視** にも追加。

### ホットキーが反応しない

- 他アプリ（IME、ランチャー等）と競合している可能性。設定で別キーへ。
- macOS では **入力監視** 権限を確認。

### マイクが認識されない

- 設定 → Advanced → Input Device で明示的にデバイスを選択。
- 設定の「自動検出」ボタンを押し、**マイクに向かって数秒喋り続ける**と、声が入っているマイクを自動で選びます（Windows では一部のドライバ方式（WDM-KS / ASIO）は安全のため自動検出の対象外）。
- macOS では **マイク** 権限を確認。

### "ご視聴ありがとうございました" 等のハルシネーション

- VAD を有効化（既定で ON）。
- VAD Min Silence を短く（例: 300ms）してこまめに無音区間で区切る。

### API 接続エラー

- 設定ウィンドウの API キーが正しいか確認（Keychain / Credential Manager に保存される）。
- ネットワーク接続を確認。
- レート制限超過の可能性（Groq の場合）。

### macOS で録音中・停止後にアプリがフリーズする

- v1.x の PortAudio スレッド競合に起因する既知のフリーズは v9 (`9c50056`) で根治済み。
- それでも刺さる場合：トレイ/メニューバーから **Force Reset** を選択すると録音セッションを強制リセットできる。
- macOS 版は、OS 側のオーディオ処理（coreaudiod）が詰まって応答が返らなくなった場合でも
  **「変換中」のまま固まらない**。録音開始が 5 秒、文字起こしが 60 秒（ローカル認識は 20 秒）
  返らなければ「オーディオシステムが応答しません」「文字起こしが応答しません」と表示して待機へ戻る。
  この状態のあいだ新しい録音は始められない（オーディオが復帰すると自動で使えるようになる）。
  復帰しないときは Mac を再起動するか、ターミナルで `sudo killall coreaudiod` を実行する。

### WinError 1314 (Windows のみ)

- Symbolic Link Privilege のエラー。`huggingface_hub` がモデルキャッシュ作成時に失敗する場合に発生。
- ユーザーディレクトリ（既定）以外を使う場合は環境変数 `HF_HOME` を設定して書き込み可能なパスに。

### ログの場所（不具合を報告するとき）

voicekey は「いつ何をしたか」（ホットキーの押下・録音の開始と停止・文字起こしの要求と応答・
貼り付け・表示の切り替えなど）を**行動ログ**としてファイルに書き続けている。
不具合の報告時はこのファイルを添えると原因を特定しやすい。

| OS | 保存先 |
| --- | --- |
| macOS | `~/Library/Logs/voicekey/voicekey-YYYY-MM-DD.log`（日付ごとに 1 ファイル） |
| Windows | `%LOCALAPPDATA%\voicekey\logs\app.log`（日付が変わるとローテート） |

- **どちらも 14 日より古いログは自動で削除される**（放っておいても溜まらない）。
- ログに文字起こしの本文は残らない（文字数だけ）。API キーも残らない。
- macOS はより細かい記録を OS のログにも出している:
  `log show --last 30m --predicate 'subsystem == "com.voicekey.app"' --info`

```bash
pyinstaller voicekey.spec --clean --noconfirm
```
