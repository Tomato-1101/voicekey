# スクリーンショット添付 — 実装計画（2026-10-18・未着手）

本人の依頼:「音声入力中にもう 1 つのキーを押すと、マウスで範囲を囲んでスクリーンショットを撮り、
音声入力の文と一緒に画像を AI（の入力欄）へ添付したい」。使用量節約のため計画だけ残す（本人指示）。
Mac のみ（Windows は停止中。再開したら [WINDOWS_CATCHUP_PLAN.md](WINDOWS_CATCHUP_PLAN.md) の対象に入れる）。

## 本人と決めたこと
- 撮影キーの既定は Claude のおすすめ、設定でどのキーにも変えられる → **既定 左⌃**
  （fn は押すだけで絵文字パネル／入力切替が出るので不採用）。
- 範囲選択の間に録音キーを離したら → **ハンズフリーに切り替える**（撮影キーを押した時点で録音を固定し、
  録音キーをもう一度押すと確定）。
- 貼り先 → **前面アプリを見て、それぞれのやり方で普通にペースト**。
- 枚数 → **押すたびに追加**。文の中に「撮った時点の位置」で `[画像1]` `[画像2]` を自動で入れ、
  どの画像が話のどこに当たるか分かるようにする。

## 動き
1. 録音中（ダブルタップ待ちを含む）に撮影キーを押す → その時点を「画像 k の位置」として記録
   （押した時刻・録音開始からの秒・その時点のライブ文字）＋録音をハンズフリーに切り替え。
2. 撮影キーを**離した瞬間**に `/usr/sbin/screencapture -i -x -o <一時 PNG>` を起動（標準の範囲選択。
   Space で窓選択、Esc で取消）。押した瞬間に起動しないのは、⌃ を押したまま選択するとクリップボード行きになる等、
   修飾キーが選択操作に干渉するため。撮影中の再押下は無視。取消なら番号を詰める。
3. ピルに撮影枚数のバッジ（SF Symbol `camera.viewfinder`＋枚数）。
4. 録音確定時に撮影が終わっていなければ、撮影完了を待ってから貼る。
5. 印の位置: 押した時のライブ文字の末尾を確定文の中で探してその直後（無ければ文字数の割合、REST 経路は経過秒の割合）
   → 近くの句読点・空白の直後へ寄せる。整形・翻訳の前に `[画像N]` を入れて通し、消えていたら相対位置で置き直す。
6. 貼り付け:
   - Claude アプリ・ChatGPT・ブラウザ等: 画像を順番に ⌘V → 最後に `[画像N]` 入りの文を ⌘V。
   - ターミナル（Terminal / iTerm / Ghostty / Warp / kitty 等）: 文を印で区切り「文1 → 画像1 → 文2 …」と差し込む。
     Claude Code は画像を貼ると自分で `[Image #n]` を入れるので、こちらの印は入れない。
   - クリップボードの退避は最初に 1 回・復元は最後に 1 回。ダブルタップの Enter は全部貼った後。
   - 履歴には `[画像N]` 入りの文だけ残す（画像は保存しない）。撮影ゼロ枚の回は今の経路を一切変えない。
7. 権限: 撮影時に画面収録の許可を確認し、無ければ要求＋案内（許可後は再起動が要る）。初回起動では要求しない。

## 貼り付けの方式について（本人の質問「キー入力でシステムに認識させてるの？普通にペーストできないの？」）
- 【事実】今の貼り付けは「文字をクリップボードに入れる → ⌘V のキー操作を合成して送る → 1 秒後にクリップボードを戻す」
  （`macos/Sources/Voicekey/Core/Paster.swift`）。アプリから見ると人が ⌘V を押したのと区別がつかず、
  受け取り側には普通のペーストとして届く。
- 【事実】キーを使わない方法は 2 つあるが、どちらも画像には弱い:
  - アクセシビリティ API で入力欄に文字を直接書く（`kAXSelectedTextAttribute`）。画像は入れられず、
    Electron・ブラウザ・ターミナルでは効かないことが多い。
  - メニューの「編集 › ペースト」をアクセシビリティ経由で押す。メニューを持つアプリでは使えるが、
    ターミナルの Claude Code は画像を ⌃V でしか受けない（ターミナル自体は画像を貼れない）。
- 【提案】⌘V／⌃V の合成のままにする。ターミナルは、⌃V の代わりに「画像ファイルのパスを文字として貼る」案もある。
  【推測】Claude Code は画像のパスを貼られると添付として扱う（ドラッグ＆ドロップと同じ）。実装前に実機で確かめる。

## 実装の手順（再開時）
- 雛形は「1 回だけ翻訳するキー」（`translateOnceKey`）。設定値 `screenshotKey`（AppConfig）→ 判定の純関数 →
  `AppController.handlePress` の保留分岐より前の追押し分岐 → `RecordContext` に撮影情報 → HUD バッジ →
  設定画面（ハンズフリーキー・再貼り付けキーの行と同じ作り、衝突警告付き。再貼り付けキーは録音中に効かないので警告しない）。
- `processAudio` の貼り付け 2 か所（ストリーミング／REST）を共通の関数にまとめてから画像対応する。
- `Paster` に連続貼り付け（文・画像を順番に、退避と復元は 1 回ずつ）を足す。画像は PNG と TIFF の両方で載せる。
  各貼り付けの後、次を書く前に待つ（画像 350ms・文 120ms 目安）。
- 新ファイル `Core/ScreenshotAttach.swift`（印の位置決め・`[画像N]` の保持確認と置き直し・ターミナル判定）。
- 委譲するなら Opus（キー状態・録音状態・クリップボードにまたがり、手戻りが高い）。課金 API を呼ぶテストは禁止。
