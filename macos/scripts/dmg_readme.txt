voicekey ベータ版 — はじめにお読みください

このたびはベータテストへのご協力ありがとうございます。

■ インストール
1. voicekey.app を「Applications」フォルダにドラッグしてください。
2. 初回起動時に警告が出る場合は、以下の手順で開いてください。

  macOS 14 (Sonoma) の場合:
    アプリケーションフォルダで voicekey.app を右クリック →「開く」→「開く」

  macOS 15 (Sequoia) 以降の場合:
    一度ダブルクリックして警告を閉じる
    → システム設定 →「プライバシーとセキュリティ」→ 下の方にある「このまま開く」

  ※ この警告は配布方式によるもので、アプリ自体の安全性に問題はありません。
    初回に一度開けば、以後は通常どおりダブルクリックで起動できます。

■ 初期設定
- 初回起動時にマイク・入力監視・アクセシビリティの許可を求められます。
  すべて許可してください（音声入力と自動貼り付けに必要です）。
- API キーなどの設定は不要です。そのまま使えます。

■ 使い方
- メニューバーのマイクアイコンから設定を開けます。
- 既定のホットキーを押しながら（または押して）話すと、文字起こしされた
  テキストがカーソル位置に入力されます。

■ アップデート
- 新しいバージョンは自動的に通知されます（毎日1回チェック）。
- メニューバーアイコン →「アップデートを確認…」で手動確認もできます。

■ プライバシー
- 録音された音声は文字起こしのため外部の音声認識サービス
  （OpenAI / Groq / ElevenLabs / Deepgram のいずれか、設定による）に送信されます。
- 機密情報・個人情報の音声入力にはご注意ください。

■ フィードバック
- メニューバーアイコン →「フィードバックを送る…」からお願いします。
- バグ報告・改善要望、どんな小さなことでも歓迎です。
