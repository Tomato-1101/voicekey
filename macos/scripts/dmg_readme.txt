voicekey ベータ版 — はじめにお読みください

このたびはベータテストへのご協力ありがとうございます。

■ インストール
1. voicekey.app を「Applications」フォルダにドラッグしてください。
2. 初回起動時に「マルウェアが含まれていないことを検証できませんでした」等の
   警告が出る場合は、以下の手順で開いてください。

  macOS 14 (Sonoma) の場合:
    アプリケーションフォルダで voicekey.app を右クリック →「開く」→「開く」

  macOS 15 (Sequoia) 以降の場合:
    1) 警告は「完了」で閉じる（「ゴミ箱に入れる」は押さない）
    2) システム設定 →「プライバシーとセキュリティ」→ 一番下までスクロール
    3) 「"voicekey" はブロックされました」の横の「このまま開く」→ Mac のパスワードを入力

  ※ macOS 15 では、この DMG を開くときにも同じ警告が出ることがあります。
    その場合も同じ手順（完了 → プライバシーとセキュリティ →「このまま開く」）で開けます。
  ※ この警告は配布方式によるもので、アプリ自体の安全性に問題はありません。
    初回に一度開けば、以後は通常どおりダブルクリックで起動できます。

■ 初期設定
- 初回起動時にマイク・入力監視・アクセシビリティの許可を求められます。
  すべて許可してください（音声入力と自動貼り付けに必要です）。
- Apple（ローカル）の文字起こしは API キー不要で、そのまま使えます（macOS 26 以降）。
- クラウドの文字起こし（Soniox / OpenAI / Microsoft / ElevenLabs / Groq）を使うときは、
  設定 →「API キー」にご自身のキーを入力してください。

■ 使い方
- メニューバーのマイクアイコンから設定を開けます。
- 既定のホットキーを押しながら（または押して）話すと、文字起こしされた
  テキストがカーソル位置に入力されます。

■ アップデート
- 新しいバージョンは自動的に確認し、ホーム画面に通知します。
- 設定 →「バージョン情報」から手動で確認することもできます。

■ プライバシー
- 録音された音声は文字起こしのため外部の音声認識サービス
  （Soniox / OpenAI / Microsoft / ElevenLabs / Groq のいずれか、設定による）に送信されます。
  Apple（ローカル）を選んだ場合は、音声は Mac の外に送信されません。
- 機密情報・個人情報の音声入力にはご注意ください。

■ フィードバック
- メニューバーアイコン →「フィードバックを送る…」からお願いします。
- バグ報告・改善要望、どんな小さなことでも歓迎です。
